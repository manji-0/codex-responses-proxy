# Support

## Where to Ask

- Bug reports: open a GitHub issue.
- Feature requests: open a GitHub issue.
- Usage questions: open a GitHub issue with context and reproduction details.
- Security issues: follow `SECURITY.md` (private report only).

## What to Include

- Proxy version (or commit SHA).
- OS and runtime details.
- Startup command and relevant flags.
- Request sample and observed output/errors.

## Out of Scope

- Support for leaked credentials or compromised environments.
- Help bypassing provider Terms of Service or policy restrictions.
- Emergency incident response with guaranteed SLA.
